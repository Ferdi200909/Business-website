# RunPro - Premium Running Shoes Business Website

A professional business website for RunPro, a premium running shoe company.

## 📋 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with gradient backgrounds
- **Multiple Pages**:
  - Home: Hero section with features and call-to-action
  - About: Company story, mission, and values
  - Products: Showcase of 6 different shoe models with pricing
  - Contact: Contact information and contact form

## 🎨 Design Highlights

- Purple gradient theme (#667eea to #764ba2)
- Smooth animations and hover effects
- Grid-based layouts for responsive design
- Professional typography and spacing

## 📄 Pages

1. **index.html** - Homepage with hero section, features, and CTA
2. **about.html** - Company information and values
3. **products.html** - Product catalog with 6 shoe models
4. **contact.html** - Contact information and inquiry form
5. **styles.css** - All styling and responsive design

## 🚀 Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Navigate through the pages using the navigation menu

## 📝 Customization

You can customize:
- Company name (replace "RunPro")
- Colors (edit the gradient colors in styles.css)
- Content and text on each page
- Product listings and pricing
- Contact information

## 📧 Contact Form

The contact form includes basic validation and shows a thank you message on submit. To enable email functionality, you'll need to integrate with a backend service.

## 📱 Responsive Breakpoints

- Desktop: Full layout
- Tablet: Adjusted spacing and font sizes
- Mobile: Single column layouts, smaller fonts
